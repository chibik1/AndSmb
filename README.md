# AndSmb

Android 端末を SMB (Windows ファイル共有) サーバーにするアプリ。root 不要。
同じ Wi-Fi にある Mac・iPhone・Windows・Android から、スマホのフォルダを開いてファイルを読み書きできる。

## ダウンロード

[Releases](https://github.com/chibik1/AndSmb/releases/latest) から最新の `AndSmb-[version].apk` をダウンロードしてインストールする。

- Android 8.0 以降
- 初めてのときは「提供元不明のアプリ」のインストールを許可する
- 新しい版は、そのまま上書きインストールできる

## 使い方

1. アプリを起動する
2. 「許可する」から「すべてのファイルへのアクセス」を許可する
3. 共有フォルダ・ユーザー名・パスワード・ポートを確認して「サーバー開始」
4. 画面に出るアドレスで、Mac・iPhone・Windows・Android  から接続する

ポートは標準で **4450** 番 (root なしでは SMB 標準の 445 番を使えないため)。

## 画面

上のタブで「サーバー」「通信量」「ログ」を切り替える。右上のボタンでテーマ (自動 / ライト / ダーク) と設定を開く。

- **サーバー**: 稼働状態と接続先アドレス (タップでコピー)。つながっている端末が地球のまわりに表示され、タップすると IP・速さ・接続時間が見られる。一番下に開始/停止ボタン
- **設定**: 共有フォルダ・ユーザー名とパスワード・ネットワーク・接続のしかた。サーバーが動いている間は変更できない
- **通信量**: 今日と起動してからの受信/送信量、直近 7 日のグラフ
- **ログ**: 接続や操作の記録。選択してコピーできる

## 接続のしかた

### Mac / iPhone

Finder の「ネットワーク」に出る端末名 (例: `PIXEL4A`) をダブルクリックする。
または「サーバへ接続」(⌘K) や iPhone のファイルアプリで、アプリに表示されるアドレスを入力する:

```
smb://PIXEL4A._smb._tcp.local/android
```

IP アドレスで `smb://<端末のIP>:4450/android` と入力してもよい。
最後の共有名 (`/android`) まで必ず入れること。入れないと共有の一覧が出ずにつながらない。

### Windows (11 24H2 以降)

コマンドプロンプトで:

```
net use Z: \\<端末のIP>\android /TCPPORT:4450 /USER:android
```

エクスプローラーの「PC」に Z: ドライブとして出る (「ネットワーク」の一覧には出ない)。
24H2 より前の Windows は 4450 番のような標準以外のポートに接続できないため使えない。

## 注意

- **家や職場など、同じ Wi-Fi の中だけで使うこと。** 通信は暗号化されないので、インターネットに公開しないこと
- Wi-Fi (または有線 LAN) でだけ動く。モバイルデータや VPN からは接続できない。Wi-Fi が切れたりアドレスが変わったりすると、サーバーは自動で止まる
- パスワードは 8 文字以上。何度も間違えると、その端末からはしばらく接続できなくなる
- SD カード・USB メモリのフォルダも共有できる (Android 11 以降)。カードの一番上は選べないので、中のフォルダを選ぶ。共有中にカードを外すとサーバーは止まる
- Mac で使うと、共有フォルダに `._ファイル名` という隠しファイルができることがある (Mac の仕様)
